# Unresolved Link Helper

一个 Obsidian 插件，增强未解析链接的创建流程：在点击未解析链接时弹出配置窗口，让你一次性指定正式标题、保存位置和模板，并自动把链接原文写入新笔记的 `aliases`。

## 功能

- 点击未解析链接（`[[外号]]`）时弹出创建配置窗口，而不是直接创建空笔记
- 可指定正式标题：若与链接文本不同，源链接会自动回写为 `[[正式名|外号]]`
- 可指定保存文件夹，不存在时自动创建
- 可指定模板，创建时自动套用（支持 `{{title}}` 和 `{{date}}` 占位符）
- 自动把链接原文合并进新笔记的 `aliases`，避免重复
- 目标笔记已存在时，不覆盖原文件，只合并别名

## 安装

### 手动安装

1. 下载 Release 中的 `main.js` 和 `manifest.json`
2. 放入你的仓库的 `.obsidian/plugins/unresolved-link-helper/` 目录
3. 在 Obsidian 设置 → 第三方插件中启用

### 通过 BRAT 安装（开发版）

在 BRAT 中添加本仓库地址即可。

## 使用

1. 在任意笔记中输入 `[[某个还不存在的人名或外号]]`
2. 点击该链接
3. 在弹窗中确认正式标题、保存位置和模板
4. 点击“创建”

## 设置

- **默认保存文件夹**：弹窗中默认填入的文件夹
- **默认模板路径**：弹窗中默认预选的模板，留空则不预选
- **创建后打开新笔记**：创建完成后是否跳转到新笔记
- **回写源链接**：正式标题与链接文本不同时，是否把源笔记中的链接更新为 `[[正式名|外号]]`

## 注意

- 插件只做 `{{title}}` 和 `{{date}}` 的简单替换，不会执行 Templater 语法
- 若同时启用 Templater 的“新建文件自动触发”，建议在人物文件夹对应的规则中关闭它，避免异步覆写已写入的别名
- 回写源链接是全局字符串替换：同一篇笔记中所有相同的 `[[外号]]` 都会被替换
